# Research and design record

Researched on 2026-10-13 against Cloudflare's current documentation and Hermes commit `f97608f178d1ffeca59860195ab7da295f7c8e5f` (v2026.9.24 / v0.21.5). Source links below are pinned where behavior depends on the Hermes release.

## Architecture decisions

| Finding | Evidence and decision |
| --- | --- |

| Public binds require Hermes authentication; `--insecure` does not provide a supported deployment strategy. | [Dashboard startup](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/hermes_cli/main_dashboard.py), [basic provider](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/plugins/dashboard_auth/basic/__init__.py). Keep native auth enabled. Access handles public user authentication; a random per-container password handles the private Worker-to-Hermes hop. |
| Hermes gated WebSockets use single-use tickets, not just cookies. | [Auth routes](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/hermes_cli/dashboard_auth/routes.py), [WebSocket gates](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/hermes_cli/web_server_chat.py). Proxy `/api/auth/ws-ticket` and the subsequent upgrade without changing the protocol. Offline testing exercises both. |
| Both web assets and the Node TUI need builds. | [Vite configuration](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/web/vite.config.ts), [TUI bundle](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/ui-tui/scripts/build.mjs), [launcher](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/hermes_cli/main_tui_launch.py). Build both during `docker build`; copy `entry.js` into `hermes_cli/tui_dist/`; use `--skip-build` at runtime. No runtime npm or package download is necessary. |
| Current Sandbox documentation uses the native Container API. | [Quickstart](https://developers.cloudflare.com/sandbox/get-started/), [Container API](https://developers.cloudflare.com/containers/api/durable-object-container/), [SDK migration](https://developers.cloudflare.com/sandbox/sdk/migrate/changes-in-1-0/). Older `getSandbox()` examples describe a different API generation. |
| Container start does not mean HTTP readiness; files are ephemeral. | [Container API](https://developers.cloudflare.com/containers/api/durable-object-container/). Coalesce parallel browser requests, poll readiness with a deadline, and describe the 15-minute inactivity timeout accurately. An open browser may keep a container active. |
| A browser dashboard exposes the user's whole agent environment. | [Hermes dashboard guide](https://hermes-agent.nousresearch.com/docs/user-guide/features/web-dashboard). Allocate a stable Durable Object from the **verified JWT subject**, not an email header or caller-selected sandbox ID. Separate users get separate files, sessions, settings, processes and private backend credentials. |
| Managed OAuth augments Access; it is not a Hermes OAuth provider configuration. | [Managed OAuth](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/managed-oauth/), [JWT verification](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/). Browser sign-in stays with Access. CLI clients use discovery, authorization code + PKCE, and a resource indicator. Both become signed Access assertions verified by the Worker. |
| AI binding can use third-party models through AI Gateway without a user-provided inference token. | [Binding methods](https://developers.cloudflare.com/ai-gateway/usage/worker-binding-methods/), [Unified Billing](https://developers.cloudflare.com/ai-gateway/features/unified-billing/), [model schema](https://developers.cloudflare.com/ai/models/openai/gpt-4.1-mini/). Use `AI.run(model, inputs, { gateway, returnRawResponse: true })`. No CLI OAuth credential is stored in the app. |
| Hermes's `custom` provider can target an intercepted HTTP endpoint. | [Provider resolution](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/hermes_cli/runtime_provider_backends.py), [API-key host matching](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/hermes_cli/runtime_provider.py). | Intercepted HTTPS needs the container CA. | [Authenticated API guide](https://developers.cloudflare.com/sandbox/network/call-an-authenticated-api/), [Hermes CA selection](https://github.com/nousresearch/hermes-agent/blob/f97608f178d1ffeca59860195ab7da295f7c8e5f/agent/ssl_verify.py). ## Compatibility established by testing

The pinned custom provider sends `reasoning_effort: medium`. GPT-4.1 mini rejects that field. The model bridge removes it for this model only, preserving it for other configured models. This was verified against real AI Gateway inference in the earlier CLI runner deployment, where all five final model calls returned HTTP 200.

A local dashboard startup initially tried to rebuild its already-built frontend because the runtime intentionally lacked `node_modules`. `--skip-build` resolved this using the supported upstream flag. The prebuilt TUI path avoids a similar runtime npm dependency. `tini` reaps child processes created by terminal sessions.

The browser terminal treats a prompt and Enter delivered in one frame as pasted content. The integration test sends Enter separately, as a real keyboard does. The stub also handles the dashboard's separate session-title model requests.

## Scope and extensions

- No Hermes source patches, Docker-in-Docker, custom terminal backend or replacement frontend.
- No inference credentials inside the agent. It can still consume the allowed model; network restrictions are not a spending quota.
- The deployed Access policy allows verified `gmail.com`, `cloudflare.com`, and `snappr.co` addresses using OR-based email-domain Include rules. This replaced the initial Everyone policy at the deployment owner's request.
- The dashboard can modify all of its own container's state. Native features requiring external services or additional package downloads remain blocked by the network policy.
- For persistence, save the workspace **and** `HERMES_HOME`. Plan consistent SQLite snapshots and restores; do not put live SQLite files on an object-storage mount. See [workspace persistence](https://developers.cloudflare.com/sandbox/files/save-and-restore-a-workspace/).
- The [coding-agents overview](https://developers.cloudflare.com/sandbox/coding-agents/) is navigation. The proposed Hermes page is a child at `/sandbox/coding-agents/hermes/`, with a card in the existing overview.

See [production verification](production.md) for results and remaining verification, separate from the local deterministic tests.
